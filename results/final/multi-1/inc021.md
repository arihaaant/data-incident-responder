# Incident inc021

**Status:** Escalated to the owner of raw.customer. Nothing was changed.

## What broke

- `not_null_stg_customers_nation_key` fail (120 rows): Got 120 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.customer`, column `c_nationkey`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `dim_customers`, `fct_daily_revenue`, `fct_orders`, `stg_customers`

**Evidence**

not_null test on stg_customers.nation_key failed with 120 null rows. raw.customer has 1500 rows, 120 null c_nationkey values (checked via COUNT and SUM). stg_customers model directly maps c_nationkey to nation_key, so nulls propagate. profile_column shows lossless conversion but nulls remain, indicating source data issue.

**Column profile** `raw.customer.c_nationkey` (integer to integer): converts without loss
