# Incident inc049

**Status:** Escalated to the owner of raw.orders. Nothing was changed.

## What broke

- `assert_orders_fresh` fail (1 rows): Got 1 result, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

Freshness check assert_orders_fresh fails on stg_orders. stg_orders is a direct select from raw.orders with no transformation. raw.orders contains 14,941 rows with _loaded_at timestamps only up to 1998-07-26, and no newer rows. The freshness test expects recent data, so the stale row originates from raw.orders where data ingestion stopped. No code change can fix missing recent rows, so the issue must be escalated to the source owner.
