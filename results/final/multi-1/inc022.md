# Incident inc022

**Status:** Escalated to the owner of raw.customer. Nothing was changed.

## What broke

- `not_null_fct_orders_region_name` fail (1892 rows): Got 1892 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.customer`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `dim_customers`, `fct_daily_revenue`, `fct_orders`, `stg_customers`

**Evidence**

fct_orders.region_name nulls (1892) come from left join to dim_customers where dim_customers has no matching row for those customer_key values (missing_cust_key=1892). dim_customers has 0 null region_name, so nulls are due to missing dim_customers rows. dim_customers is built via inner joins of stg_customers -> stg_nations -> stg_regions, so customers whose nation_key does not exist in raw.nation (or region missing) are dropped, causing downstream nulls. This is a data issue in raw.customer (invalid or new nation_key) or missing raw.nation rows, i.e., upstream data change.
