# Incident inc048

**Status:** Escalated to the owner of raw.orders. Nothing was changed.

## What broke

- `assert_orders_fresh` fail (1 rows): Got 1 result, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

stg_orders simply selects from raw.orders; the freshness check assert_orders_fresh fails on stg_orders. raw.orders _loaded_at values range from 1992-01-02 to 1998-07-28, far older than the allowed freshness window, indicating source data is delayed or not being refreshed. No transformation in stg_orders can fix this, so the issue originates in the source raw.orders.

No change was made to the warehouse. The data has to be corrected where it comes from.
