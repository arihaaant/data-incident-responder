## What was done

Proposed a change to `models/staging/stg_orders.sql`. The original model filtered out rows where `_loaded_at` was on or after 1998-06-15, causing recent orders to be dropped. This led to failing freshness and relationship checks. The filter has been removed to include all source rows, restoring correct row counts and fixing the checks while keeping the rest of the model unchanged.

```diff
--- a/models/staging/stg_orders.sql
+++ b/models/staging/stg_orders.sql
@@ -7,4 +7,4 @@
     o_orderpriority as priority,
     _loaded_at as loaded_at
 from {{ source('raw', 'orders') }}
-where _loaded_at < date '1998-06-15'
+-- Removed erroneous date filter that excluded recent rows
```

- **Tested in a copy of the warehouse:** every check passed.
- **Reviewer:** approved. Fix removes erroneous date filter that was dropping recent rows, directly addressing the root cause without masking data or altering column logic.
