# Incident inc008

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `model.tpch_warehouse.stg_lineitem` error: Runtime Error in model stg_lineitem (models/staging/stg_lineitem.sql)

## Diagnosis

- **Started at:** `source.raw.lineitem`, column `l_extended_price`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_lineitem`

**Evidence**

The raw.lineitem table has column l_extended_price (underscore) while stg_lineitem model selects l_extendedprice (no underscore), causing binder error. No data loss; just rename. Fix by updating model to reference l_extended_price.

## What was done

Proposed a change to `models/staging/stg_lineitem.sql`. The source table raw.lineitem defines the column as `l_extended_price` (with an underscore). The staging model incorrectly referenced `l_extendedprice`, causing a binder error. Updated both occurrences to the correct column name, preserving all other column selections and aliases. No other changes were made to maintain existing contracts and downstream expectations.
