# Incident inc043

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `unique_stg_customers_customer_key` fail (337 rows): Got 337 results, configured to fail if != 0

## Diagnosis

- **Started at:** `model.stg_customers`
- **Cause:** a change in a model
- **Downstream models affected:** `dim_customers`, `fct_daily_revenue`, `fct_orders`

**Evidence**

raw.customer has 1500 rows and 1500 distinct c_custkey, so source is unique. stg_customers model SQL selects all rows then UNION ALL adds a second copy of rows where c_mktsegment='BUILDING', creating duplicates for those keys. This explains 337 duplicate customer_key rows reported by the uniqueness check.

```sql
SELECT COUNT(*) AS total_rows FROM raw.customer
```
```sql
SELECT COUNT(DISTINCT customer_key) AS distinct_keys FROM raw.customer
```
```sql
SELECT COUNT(*) AS total_rows, COUNT(DISTINCT c_custkey) AS distinct_keys FROM raw.customer
```

</details>

## What was done

Proposed a change to `models/staging/stg_customers.sql`. Removed the erroneous UNION ALL that duplicated rows where c_mktsegment = 'BUILDING'. The original model unintentionally added a second copy of those rows, causing 337 duplicate customer_key values and failing the uniqueness test. By selecting directly from the source without the union, we preserve the original column list and types while ensuring each customer appears only once.

```diff
--- a/models/staging/stg_customers.sql
+++ b/models/staging/stg_customers.sql
@@ -7,7 +7,3 @@
     c_mktsegment as market_segment,
     c_acctbal as account_balance
 from {{ source('raw', 'customer') }}
-union all
-select c_custkey, c_name, c_address, c_phone, c_nationkey, c_mktsegment, c_acctbal
-from {{ source('raw', 'customer') }}
-where c_mktsegment = 'BUILDING'
```

- **Tested in a copy of the warehouse:** every check passed.
- **Reviewer:** approved. Fix removes the erroneous UNION ALL that duplicated rows, directly addressing the root cause of duplicate customer_key values. No masking or data alteration; simply restores correct one-to-one mapping from source.
