## What broke

- `model.tpch_warehouse.stg_customers` error: Runtime Error in model stg_customers (models/staging/stg_customers.sql)

## Diagnosis

- **Started at:** `source.raw.customer`, column `c_market_segment`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `dim_customers`, `fct_daily_revenue`, `fct_orders`, `stg_customers`

**Evidence**

raw.customer table shows column c_market_segment (renamed from c_mktsegment). stg_customers model references old name c_mktsegment, causing binder error. Policy: renamed column is lossless, fix by updating staging model. Root is source.raw.customer.

Updated the staging model to reference the new column name while preserving all other columns and aliases. This resolves the binder error without altering column types or other logic.
