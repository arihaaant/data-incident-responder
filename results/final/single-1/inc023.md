# Incident inc023

**Status:** Escalated to the owner of raw.lineitem. Nothing was changed.

## What broke

- `not_null_stg_lineitem_order_key` fail (1550 rows): Got 1550 results, configured to fail if != 0
- `not_null_stg_lineitem_order_line_id` fail (1550 rows): Got 1550 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.lineitem`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_lineitem`

**Evidence**

The not_null checks on stg_lineitem failed for 1550 rows. In stg_lineitem, order_key maps directly to raw.lineitem.l_orderkey. Querying raw.lineitem shows 1550 rows with l_orderkey NULL, confirming the source data is missing order keys. Hence the problem originates in the raw lineitem source and must be escalated.
