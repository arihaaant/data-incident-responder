# Incident inc026

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `not_null_stg_lineitem_extended_price` fail (29778 rows): Got 29778 results, configured to fail if != 0

## Diagnosis

- **Started at:** `model.stg_lineitem`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`

**Evidence**

The test not_null_stg_lineitem_extended_price failed with 29,778 null extended_price rows. In stg_lineitem.sql the column extended_price was defined as `case when l_returnflag = 'N' then l_extendedprice end`, which returns NULL for any row where l_returnflag is not 'N'. This caused the nulls. Changing the expression to simply `l_extendedprice` removes the unintended nulls. A trial patch with this change passes all checks.
