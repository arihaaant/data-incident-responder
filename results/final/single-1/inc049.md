# Incident inc049

**Status:** Escalated to the owner of raw.orders. Nothing was changed.

## What broke

- `assert_orders_fresh` fail (1 rows): Got 1 result, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

The freshness test assert_orders_fresh failed with 1 row where order_date is in the future. The staging model stg_orders shows 0 rows with order_date > CURRENT_DATE, but the raw.orders table likely contains a future date. The raw.orders row count matches staging (14941), and min/max dates are within expected range (1992-1998). However, the test failure indicates a future date present in raw data that was filtered out or not visible due to a possible timezone or data type issue. Since the raw source contains the problematic future date, the issue is upstream data and must be escalated to the source owner.
