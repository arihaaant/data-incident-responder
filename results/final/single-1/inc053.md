# Incident inc053

**Status:** Escalated to the owner of raw.orders. Nothing was changed.

## What broke

- `assert_orders_fresh` fail (1 rows): Got 1 result, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

The assert_orders_fresh check fails because loaded_at values in staging.stg_orders are all from the 1990s. These values come directly from raw.orders._loaded_at, which contains historic timestamps rather than recent load timestamps. Row counts match between raw.orders and staging.stg_orders, indicating no loss in the model. Therefore the problem originates in the source data.
