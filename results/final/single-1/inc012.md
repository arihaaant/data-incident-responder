# Incident inc012

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `model.tpch_warehouse.stg_orders` error: Compilation Error in model stg_orders (models/staging/stg_orders.sql)

## Diagnosis

- **Started at:** `model.stg_orders`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`

**Evidence**

The stg_orders model had a contract requiring order_date to be DATE, but the source column o_orderdate is VARCHAR. Profile of raw.orders.o_orderdate shows all 15000 rows are convertible losslessly using format %m/%d/%Y. Adding a conversion with strptime(trim(o_orderdate), '%m/%d/%Y')::date resolves the contract mismatch and all checks now pass.

**Column profile** `raw.orders.o_orderdate` (varchar to date): converts without loss
