## What broke

- `unique_stg_orders_order_key` fail (363 rows): Got 363 results, configured to fail if != 0

## Diagnosis

- **Started at:** `model.stg_orders`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`

**Evidence**

The unique_stg_orders_order_key test failed with 363 duplicate order_key values. The stg_orders model contained a UNION ALL that duplicated rows from raw.orders, especially those with order_status = 'P', causing non‑unique order_key values. Removing the UNION ALL eliminates the duplicate rows, and a trial patch with the simplified SELECT passes all checks.
