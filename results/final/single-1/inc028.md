## What broke

- `not_null_fct_orders_region_name` fail (14625 rows): Got 14625 results, configured to fail if != 0

## Diagnosis

- **Started at:** `model.fct_orders`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`

**Evidence**

The not_null_fct_orders_region_name test failed with 14625 null region_name values. In fct_orders the join to dim_customers incorrectly used o.order_key = c.customer_key, causing mismatched rows and null region_name. Changing the join condition to o.customer_key = c.customer_key correctly links each order to its customer, restoring region_name values. After applying this patch, all tests pass.
