# Incident inc042

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `unique_dim_customers_customer_key` fail (1500 rows): Got 1500 results, configured to fail if != 0

## Diagnosis

- **Started at:** `model.dim_customers`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`

**Evidence**

The unique test on dim_customers.customer_key failed with 1500 duplicate rows. stg_customers has 1500 unique keys, but dim_customers has 7500 rows, indicating duplication from joins. The original dim_customers SQL incorrectly joined stg_regions with condition `n.region_key = n.region_key`, which is always true, causing a Cartesian product with all regions. Fixing the join to `n.region_key = r.region_key` removes the duplication. After applying the patch, all tests pass.
