# Incident inc021

**Status:** Escalated to the owner of raw.customer. Nothing was changed.

## What broke

- `not_null_stg_customers_nation_key` fail (120 rows): Got 120 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.customer`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `dim_customers`, `fct_daily_revenue`, `fct_orders`, `stg_customers`

**Evidence**

The not_null check on stg_customers.nation_key failed with 120 rows. In raw.customer, c_nationkey has 120 nulls (out of 1500 rows). The staging model just selects c_nationkey as nation_key, so the nulls come from source data. No code change can fix missing source values; the source owner must address the data quality issue.

```sql
SELECT COUNT(*) AS total, COUNT(*) - COUNT(nation_key) AS nulls FROM raw.customer
```
```sql
SELECT COUNT(*) AS total, SUM(CASE WHEN c_nationkey IS NULL THEN 1 ELSE 0 END) AS nulls FROM raw.customer
```

</details>

## What was done

No change was made to the warehouse. The data has to be corrected where it comes from.
