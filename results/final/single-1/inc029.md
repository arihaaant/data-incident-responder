## Diagnosis

- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`

**Evidence**

The not_null_stg_orders_order_date test failed with 363 nulls. In raw.orders, o_orderdate has no nulls (15000 rows, 0 nulls). The stg_orders model sets order_date using a CASE that nulls out rows where o_orderstatus = 'P', creating the nulls. Removing the CASE restores order_date for all rows, fixing the test.
