## What broke

- `unique_stg_lineitem_order_line_id` fail (14739 rows): Got 14739 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.lineitem`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_lineitem`

**Evidence**

The unique test on stg_lineitem.order_line_id failed with 14739 duplicate rows. A query grouping by all raw.lineitem columns showed 14739 duplicate rows, indicating exact duplicate records in raw.lineitem. Policy allows deduplication in the staging model for identical duplicate batches. Applying SELECT DISTINCT in stg_lineitem removes the duplicates and all tests now pass.
