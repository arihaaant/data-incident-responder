# Incident inc020

**Status:** Escalated to the owner of raw.orders. Nothing was changed.

## What broke

- `not_null_stg_orders_order_date` fail (750 rows): Got 750 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

The not_null test on stg_orders.order_date failed with 750 nulls. Raw.orders contains 15000 rows, 750 of which have o_orderdate NULL. Stg_orders simply selects o_orderdate, so nulls are introduced upstream. Issue is upstream data; must be escalated.
