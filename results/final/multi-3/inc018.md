# Incident inc018

**Status:** Escalated to the owner of raw.lineitem. Nothing was changed.

## What broke

- `not_null_stg_lineitem_extended_price` fail (8751 rows): Got 8751 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.lineitem`, column `l_extendedprice`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_lineitem`

**Evidence**

raw.lineitem contains 8,751 null values in l_extendedprice out of 60,175 rows (SELECT COUNT(*) FILTER (WHERE l_extendedprice IS NULL)). stg_lineitem directly maps this column to extended_price, so the nulls appear in the staging model, causing the not_null test to fail. The problem originates in the source data, not in any transformation.
