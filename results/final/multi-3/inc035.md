# Incident inc035

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `unique_stg_lineitem_order_line_id` fail (5639 rows): Got 5639 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.lineitem`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_lineitem`

**Evidence**

raw.lineitem has 65,814 rows but only 60,175 distinct order_key-line_number combos (order_line_id). Duplicate rows are exact copies (e.g., orderkey 96 linenumber 2 appears twice with identical column values). The unique_stg_lineitem_order_line_id check fails with 5,639 duplicate rows, which originates from these source duplicates. Policy: identical duplicate rows indicate a batch delivered twice, so we can deduplicate in the staging model.

## What was done

Proposed a change to `models/staging/stg_lineitem.sql`. Added a CTE to reference the source and wrapped the SELECT in DISTINCT to remove exact duplicate rows that were causing the unique_stg_lineitem_order_line_id check to fail. This preserves all column names, types, and derived calculations while ensuring only one copy of each identical row is loaded into the staging model.

```diff
--- a/models/staging/stg_lineitem.sql
+++ b/models/staging/stg_lineitem.sql
@@ -1,4 +1,9 @@
-select
+with raw_lineitem as (
+    select *
+    from {{ source('raw', 'lineitem') }}
+)
+
+select distinct
     l_orderkey || '-' || l_linenumber as order_line_id,
     l_orderkey as order_key,
     l_linenumber as line_number,
@@ -11,4 +16,4 @@
     l_returnflag as return_flag,
     l_shipdate as ship_date,
     l_extendedprice * (1 - l_discount) as net_revenue
-from {{ source('raw', 'lineitem') }}
+from raw_lineitem
```

- **Tested in a copy of the warehouse:** every check passed.
- **Reviewer:** approved. Fix correctly deduplicates exact duplicate source rows using DISTINCT, addressing the root cause without masking data or altering column semantics. Policy permits deduplication in staging for identical batch duplicates.
