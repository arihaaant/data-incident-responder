## What was done

Proposed a change to `models/marts/fct_daily_revenue.sql`. Removed `priority` from the GROUP BY clause. The original grouping on `priority` caused multiple rows per region per day, violating the test that expects a single row per region per day. The SELECT list never referenced `priority`, so dropping it from GROUP BY resolves the duplicate rows while preserving the intended aggregations.

--- a/models/marts/fct_daily_revenue.sql
