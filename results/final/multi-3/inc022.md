# Incident inc022

**Status:** Escalated to the owner of raw.nation. Nothing was changed.

## What broke

- `not_null_fct_orders_region_name` fail (1892 rows): Got 1892 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.nation`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `dim_customers`, `fct_daily_revenue`, `fct_orders`, `stg_nations`

**Evidence**

marts.fct_orders has 1892 null region_name rows; these correspond to orders whose customer_key missing in marts.dim_customers (missing_cust=1892). marts.dim_customers has 1319 rows vs staging.stg_customers 1500 rows, indicating 181 customers dropped due to inner joins on stg_nations and stg_regions. This suggests missing or mismatched nation/region keys in the raw.nation (or raw.region) source, causing customers to be excluded upstream. Since the nulls stem from missing source reference data, the issue is upstream data and should be escalated to the source owner.
