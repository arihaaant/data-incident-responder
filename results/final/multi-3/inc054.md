# Incident inc054

**Status:** Escalated to the owner of raw.orders. Nothing was changed.

## What broke

- `assert_orders_fresh` fail (1 rows): Got 1 result, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

stg_orders pulls _loaded_at directly from raw.orders; max loaded_at in staging.stg_orders is 1998-06-19, far older than freshness threshold, causing assert_orders_fresh to return 1 stale row. No transformation in stg_orders alters timestamps, so the stale data originates from the source raw.orders.
