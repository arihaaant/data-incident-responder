## What was done

Proposed a change to `models/staging/stg_orders.sql`. Removed the erroneous filter `where year(o_orderdate) < 1998` which was unintentionally dropping recent orders. This restores the full set of order rows, aligning the row count with the source and fixing the relationships and freshness checks. No other columns or types were altered.

```diff
--- a/models/staging/stg_orders.sql
```
