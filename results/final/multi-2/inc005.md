**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `model.tpch_warehouse.stg_customers` error: Runtime Error in model stg_customers (models/staging/stg_customers.sql)

## Diagnosis

- **Started at:** `source.raw.customer`, column `c_account_balance`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `dim_customers`, `fct_daily_revenue`, `fct_orders`, `stg_customers`

**Evidence**

stg_customers model fails to compile because it references c_acctbal, which is not present in raw.customer. raw.customer schema shows column c_account_balance instead. This schema drift originates from the source; fixing the staging model to use c_account_balance will resolve the error.

## What was done

Proposed a change to `models/staging/stg_customers.sql`. The source raw.customer schema uses column name c_account_balance, not c_acctbal. Updated the staging model to reference the correct column while preserving all other column selections and aliases. This resolves the binder error without altering column types or other logic.

```diff
--- a/models/staging/stg_customers.sql
+++ b/models/staging/stg_customers.sql
@@ -5,5 +5,5 @@
```
