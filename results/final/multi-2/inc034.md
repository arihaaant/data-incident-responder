# Incident inc034

**Status:** Escalated to the owner of raw.lineitem. Nothing was changed.

## What broke

- `unique_stg_lineitem_order_line_id` fail (1550 rows): Got 1550 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.lineitem`, column `order_line_id`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_lineitem`

**Evidence**

raw.lineitem has 61,725 rows but only 60,175 distinct order_line_id (l_orderkey||'-'||l_linenumber). Duplicate groups count = 1,550 matching failing check. Example duplicate rows for order_key 193, line_number 3 are identical duplicates, indicating source delivered duplicate rows. Staging model simply passes through, so issue originates in raw source.
