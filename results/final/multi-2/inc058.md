## Diagnosis

- **Started at:** `model.stg_orders`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`

**Evidence**

raw.orders has 15000 rows but stg_orders only 7667 rows. The stg_orders model filters out rows where o_orderstatus = 'O'. This filter drops many orders, causing 29165 lineitem rows to lack matching orders and 1 stale order row. The failing relationship check and freshness test stem from this truncation.

## What was done

Proposed a change to `models/staging/stg_orders.sql`. The original model filtered out rows where o_orderstatus = 'O', which caused missing order records and downstream relationship failures. Removing the filter restores the full set of orders, aligning row counts with the source and satisfying the relationship and freshness checks.
