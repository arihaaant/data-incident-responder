# Incident inc025

**Status:** Escalated. A fix was attempted but did not pass review, so nothing was changed.

## What broke

- `not_null_fct_orders_region_name` fail (14744 rows): Got 14744 results, configured to fail if != 0

## Diagnosis

- **Started at:** `model.stg_customers`
- **Cause:** a change in a model
- **Downstream models affected:** `dim_customers`, `fct_daily_revenue`, `fct_orders`

**Evidence**

dim_customers has 0 null region_name, but fct_orders has 14744 nulls. The nulls arise from left join on dim_customers where many orders' customer_key do not match any dim_customers row. stg_orders has 1000 distinct customers, while dim_customers only 24 rows, indicating dim_customers is not including all customers. Likely dim_customers model filters or joins incorrectly, dropping customers. The upstream raw tables likely contain all customers; stg_customers simply selects raw.customer fields. Therefore the problem started in dim_customers model (code change) and can be patched by fixing its join logic to include all customers.
