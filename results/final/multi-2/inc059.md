- `relationships_stg_lineitem_order_key__order_key__ref_stg_orders_` fail (769 rows): Got 769 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

stg_lineitem has 60175 rows, stg_orders only 14800 rows. Relationship test shows 769 lineitem rows with order_key not in stg_orders. Query shows raw.orders contains order_keys missing from stg_orders, indicating orders not loaded into staging. Freshness test fails (1 row) indicating orders data not refreshed. The filter in stg_orders does not exclude these keys (as_of is far future), so missing rows stem from upstream source not delivering recent orders.
