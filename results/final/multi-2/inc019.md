# Incident inc019

**Status:** Escalated to the owner of raw.lineitem. Nothing was changed.

## What broke

- `not_null_stg_lineitem_discount` fail (12002 rows): Got 12002 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.lineitem`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_lineitem`

**Evidence**

raw.lineitem has 60,175 rows with 12,002 null values in l_discount (SELECT COUNT(*) ...). stg_lineitem directly selects l_discount without transformation, so nulls propagate, causing not_null test failure.
