# Incident inc022

**Status:** Escalated to the owner of raw.orders. Nothing was changed.

## What broke

- `not_null_fct_orders_region_name` fail (1892 rows): Got 1892 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

fct_orders.region_name nulls (1892) come from left join to dim_customers where customer_key missing (missing_cust=1892). dim_customers has fewer customers (1319) than stg_customers (1500) and orders reference missing customers. Thus source orders contain customer_key values not present in source customers, causing null region_name. No code error in models.
