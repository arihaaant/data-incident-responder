# Incident inc026

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `not_null_stg_lineitem_extended_price` fail (29778 rows): Got 29778 results, configured to fail if != 0

## Diagnosis

- **Started at:** `model.stg_lineitem`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`

**Evidence**

The not_null_stg_lineitem_extended_price test failed with 29,778 nulls. In stg_lineitem, extended_price was defined as `case when l_returnflag = 'N' then l_extendedprice end`, which yields NULL for rows where return_flag != 'N'. The raw source column l_extendedprice is never null, so the nulls are introduced by the model. Changing the expression to directly select l_extendedprice removes the unintended nulls and all checks now pass.
