# Incident inc010

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `model.tpch_warehouse.stg_lineitem` error: Runtime Error in model stg_lineitem (models/staging/stg_lineitem.sql)

## Diagnosis

- **Started at:** `model.stg_lineitem`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`

**Evidence**

The stg_lineitem model failed with a Binder Error because the expression `l_extendedprice * (1 - l_discount)` attempted to subtract a VARCHAR (l_discount) from a numeric value. Profiling shows l_discount is a VARCHAR that can be losslessly cast to DECIMAL(15,2). Adding an explicit cast to decimal for l_discount (and using the cast in the net_revenue calculation) resolves the type mismatch. A try_patch run confirms the build now passes with no test failures.

**Column profile** `raw.lineitem.l_discount` (varchar to decimal(15,2)): converts without loss

## What was done

Proposed a change to `models/staging/stg_lineitem.sql`. Adding an explicit cast to decimal for l_discount (and using the cast in the net_revenue calculation) resolves the type mismatch. A try_patch run confirms the build now passes with no test failures.
