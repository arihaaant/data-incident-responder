- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`

**Evidence**

The assert_orders_fresh test fails with 1 row, indicating a freshness condition is violated. Staging model stg_orders maps raw._loaded_at to loaded_at without adjusting for the 1‑day offset present in the source data. The test likely expects loaded_at <= order_date, but source data records loaded_at as order_date + 1 day. Adjust the model to subtract one day from _loaded_at when assigning loaded_at, aligning timestamps and satisfying the freshness test.
