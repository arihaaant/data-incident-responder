# Incident inc039

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `unique_stg_parts_part_key` fail (200 rows): Got 200 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.part`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_parts`

**Evidence**

The unique_stg_parts_part_key test failed with 200 duplicate rows. raw.part has 2,200 rows but only 2,000 distinct p_partkey values, indicating duplicates. A query grouping by p_partkey shows each duplicate has identical values for all other columns, confirming exact duplicate batches. Adding a deduplication step (row_number partition by p_partkey) in stg_parts removes the duplicates, and try_patch confirms all checks now pass.
