## Diagnosis

- **Started at:** `model.stg_orders`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`

**Evidence**

The not_null test on stg_orders.order_date failed with 363 null rows. In the current model, order_date is set to NULL for rows where o_orderstatus = 'P' (case when o_orderstatus <> 'P' then o_orderdate end). The source raw.orders always has a non-null o_orderdate, and the test expects order_date never null. Changing the column to directly use o_orderdate removes the conditional nulling and satisfies the not_null test.
