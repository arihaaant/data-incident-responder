# Incident inc018

**Status:** Escalated to the owner of raw.lineitem. Nothing was changed.

## What broke

- `not_null_stg_lineitem_extended_price` fail (8751 rows): Got 8751 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.lineitem`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_lineitem`

**Evidence**

The not_null_stg_lineitem_extended_price check failed with 8751 rows. In raw.lineitem, the column l_extendedprice has 8751 null values (total rows 60175, non-null 51424). The staging model stg_lineitem directly maps l_extendedprice to extended_price without transformation, so the nulls are propagated. Therefore the issue originates in the source raw.lineitem data, not in any dbt model code.
