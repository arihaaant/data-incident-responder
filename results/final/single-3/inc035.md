# Incident inc035

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `unique_stg_lineitem_order_line_id` fail (5639 rows): Got 5639 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.lineitem`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_lineitem`

**Evidence**

The unique_stg_lineitem_order_line_id test failed with 5639 duplicate rows. Raw lineitem table contains identical duplicate rows (e.g., orderkey 96, linenumber 2 appears twice). According to policy, identical duplicate rows indicate a batch was delivered twice and should be deduplicated in the staging model. Adding DISTINCT to the select removes these duplicates, and a trial patch shows all checks now pass.
