# Incident inc030

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `not_null_stg_lineitem_discount` fail (5419 rows): Got 5419 results, configured to fail if != 0

## Diagnosis

- **Started at:** `model.stg_lineitem`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`

**Evidence**

The not_null_stg_lineitem_discount test failed with 5,419 null discount values. In stg_lineitem model, discount was derived using `case when l_discount > 0 then l_discount end`, which turns zero discounts into NULL, violating the not‑null test. Raw `raw.lineitem.l_discount` contains valid numeric values (including zeros). Changing the model to select `l_discount` directly removes the unintended NULLs. A trial patch with this change passes all checks.
