# Incident inc012

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `model.tpch_warehouse.stg_orders` error: Compilation Error in model stg_orders (models/staging/stg_orders.sql)

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

The stg_orders model has a contract that order_date must be DATE, but the raw.orders.o_orderdate column is VARCHAR. profile_column shows the column can be losslessly converted using the format %m/%d/%Y. Applying strptime(trim(o_orderdate), '%m/%d/%Y')::date in the model resolves the contract mismatch and all checks now pass.

**Column profile** `raw.orders.o_orderdate` (varchar to date): converts without loss
