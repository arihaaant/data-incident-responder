# Incident inc029

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `not_null_stg_orders_order_date` fail (363 rows): Got 363 results, configured to fail if != 0

## Diagnosis

- **Started at:** `model.stg_orders`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`

**Evidence**

The not_null_stg_orders_order_date test failed with 363 null order_date values. In stg_orders the order_date column is set using a CASE that nulls the date when order_status = 'P'. The not_null test expects every order to have a date, so the CASE is wrong. Raw.orders has no null order_date values. Changing the model to map o_orderdate directly removes the nulls, and a try_patch run shows all checks now pass.
