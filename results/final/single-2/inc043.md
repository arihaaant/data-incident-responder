# Incident inc043

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `unique_stg_customers_customer_key` fail (337 rows): Got 337 results, configured to fail if != 0

## Diagnosis

- **Started at:** `model.stg_customers`
- **Cause:** a change in a model
- **Downstream models affected:** `dim_customers`, `fct_daily_revenue`, `fct_orders`

**Evidence**

The unique_stg_customers_customer_key test failed with 337 duplicate rows. The stg_customers model performed a UNION ALL of raw.customer with itself (filtered on market_segment='BUILDING'), duplicating rows for that segment and causing non‑unique customer_key values. Removing the UNION ALL eliminates the duplicates, and a trial patch shows all tests now pass.
