## What broke

- `model.tpch_warehouse.stg_customers` error: Runtime Error in model stg_customers (models/staging/stg_customers.sql)

## Diagnosis

- **Started at:** `source.raw.customer`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `dim_customers`, `fct_daily_revenue`, `fct_orders`, `stg_customers`

**Evidence**

The stg_customers model referenced column c_nationkey which does not exist in raw.customer. The raw table has column c_nation_key. This column rename caused a runtime binder error. According to policy, renamed columns are handled by updating the staging model. Hence patch the model to use c_nation_key.
