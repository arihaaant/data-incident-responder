## Diagnosis

- **Started at:** `model.stg_customers`

- **Downstream models affected:** `dim_customers`, `fct_daily_revenue`, `fct_orders`

**Evidence**

The not_null test on stg_customers.market_segment failed with 288 null rows. The model used nullif(trim(c_mktsegment), 'MACHINERY'), which incorrectly turned the valid value 'MACHINERY' into NULL, causing the failure. Removing the nullif (keeping only trim) restores the original values and passes all tests, as confirmed by try_patch.
