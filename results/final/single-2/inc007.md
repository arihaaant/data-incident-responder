## Diagnosis

- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_lineitem`

**Evidence**

Updating the model to use l_discount_rate and adjusting net_revenue fixes the issue. The source change is upstream, but the model SQL is incorrect, so cause is code_change. Patch the staging model accordingly.
