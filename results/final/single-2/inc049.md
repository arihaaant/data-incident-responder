## What broke

- `assert_orders_fresh` fail (1 rows): Got 1 result, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

The assert_orders_fresh test fails with 1 row. Loaded_at values in staging.stg_orders range from 1992-01-02 to 1998-07-26, indicating the source raw.orders data is stale and does not meet the freshness expectation. The staging model simply selects from raw.orders without transformation, so the issue originates from the source data.
