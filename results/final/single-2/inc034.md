# Incident inc034

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `unique_stg_lineitem_order_line_id` fail (1550 rows): Got 1550 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.lineitem`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_order_items`, `fct_orders`, `stg_lineitem`

**Evidence**

The unique_stg_lineitem_order_line_id test failed with 1550 duplicate rows. Raw.lineitem contains duplicate rows that are identical across all columns (e.g., orderkey 871 linenumber 7 appears twice with identical values). According to policy, identical duplicate rows are a batch delivered twice and should be deduplicated in the staging model. Adding SELECT DISTINCT removes the duplicate rows while preserving all columns and types, fixing the uniqueness test without altering data semantics.
