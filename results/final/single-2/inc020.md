# Incident inc020

**Status:** Escalated to the owner of raw.orders. Nothing was changed.

## What broke

- `not_null_stg_orders_order_date` fail (750 rows): Got 750 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

The failing test not_null_stg_orders_order_date reported 750 rows with null order_date. Querying raw.orders shows 750 null values in o_orderdate (SELECT COUNT(*) total, SUM(CASE WHEN o_orderdate IS NULL THEN 1 ELSE 0 END) nulls FROM raw.orders). Since the nulls exist in the source table, the issue originates upstream; the staging model simply passes through the column. Therefore the problem is upstream data and must be escalated to the source owner.
