## What broke

- `unique_stg_orders_order_key` fail (1200 rows): Got 1200 results, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

The unique_stg_orders_order_key test failed with 1200 duplicate rows. Raw.orders has 16200 rows but only 15000 distinct order_key values, indicating duplicate order rows in the source. Adding DISTINCT in the staging model removes the duplicates, and try_patch shows all tests now pass.
