# Incident inc048

**Status:** Escalated to the owner of raw.orders. Nothing was changed.

## What broke

- `assert_orders_fresh` fail (1 rows): Got 1 result, configured to fail if != 0

## Diagnosis

- **Started at:** `source.raw.orders`
- **Cause:** data arriving from upstream
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`, `stg_orders`

**Evidence**

The staging model stg_orders correctly maps raw.orders columns (order_key, customer_key, order_status, total_price, order_date, priority, loaded_at) and row counts match (14957 rows). All loaded_at values are historic dates (e.g., 1996-01-03) far older than the current date, causing the assert_orders_fresh check to fail. Since the data itself is stale in the source raw.orders, the problem originates upstream and must be escalated to the source owner.
