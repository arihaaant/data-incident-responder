# Incident inc025

**Status:** Fix proposed. Needs a human review before it is merged.

## What broke

- `not_null_fct_orders_region_name` fail (14744 rows): Got 14744 results, configured to fail if != 0

## Diagnosis

- **Started at:** `model.dim_customers`
- **Cause:** a change in a model
- **Downstream models affected:** `fct_daily_revenue`, `fct_orders`

**Evidence**

The failing check not_null_fct_orders_region_name reported 14744 null region_name values in marts.fct_orders. fct_orders gets region_name from dim_customers via a left join on customer_key. dim_customers only has 24 rows and no null region_name, indicating most customers are missing from dim_customers. The dim_customers model incorrectly joins stg_customers to stg_nations on c.customer_key = n.nation_key and uses an inner join to stg_regions, causing most rows to be dropped. Correcting the join to c.nation_key = n.nation_key and using left joins preserves all customers, eliminating null region_name in fct_orders and fixing the failing test.
